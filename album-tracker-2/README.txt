ALBUM TRACKER 2

A separate copy of the Album Tracker. It has its own albums, folders and
settings, and never reads or changes the original Album Tracker.

How to start it
1. Put this whole "Album Tracker 2" folder somewhere NEW (e.g. Documents).
   Don't put it inside the old Album Tracker folder or over its files.
2. Double-click Start_Album_Tracker_2.bat.
3. It opens at  http://localhost:8091/index.html
   (The old one stays at http://localhost:8080 - different address,
   different app.)
4. Optional: click the install icon in the address bar to install it as
   an app called "Album Tracker 2".

Your albums are saved in your browser for this address. Use Export now and
then to keep a backup file. Don't use "Clear site data" / "Clear browsing
data", since that would delete them.

Moving albums over from the old tracker (optional)
  In the OLD tracker click Export, then in Album Tracker 2 click Import and
  pick that file. That's a one-time copy; the two stay separate afterwards.
